# Functional Specification

## Features

### Board

- Display four columns
  - Backlog
  - Todo
  - In Progress
  - Done

### Tasks

- Create task
- Edit task
- Delete task
- Move task between columns
- Display labels
- Display priority
- Display due date

### Drag & Drop

- Drag task to another column
- Drag indicator
- Highlight destination column
- Smooth animation

### Persistence

- Save board to localStorage
- Load board on startup

### Validation

Task title is required.

Maximum title length: 100 characters.

Due date is optional.

Labels are optional.
