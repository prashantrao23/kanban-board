# Acceptance Criteria

## Board

- Four columns visible
- Responsive layout

## Tasks

- Can create task
- Can edit task
- Can delete task

## Drag & Drop

- Move between columns
- Animation is smooth
- Column highlights

## Validation

- Empty title not allowed

## Persistence

- Refresh keeps all tasks

## Performance

- Drag remains smooth
- No unnecessary re-renders

## Accessibility

- Keyboard accessible
- Focus indicators visible
- Proper ARIA labels

## Code Quality

- TypeScript strict mode
- No ESLint errors
- No console warnings
